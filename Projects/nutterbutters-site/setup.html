Before you start — what you need

Make sure you have all of these ready. The bot runs as a desktop EXE — no Python knowledge needed. You only need a browser and a Windows PC.

🖥️ Windows / Mac / Linux PC 🟠 Shopee PH account 🔵 Lazada PH account 🟣 Zalora PH account (free) 🖥️ gui.py — desktop dashboard ❌ TikTok Shop — not supported 📱 5 Threads/Instagram accounts 🌐 Chrome browser ☁️ Meta developer account (free)
❌
TikTok Shop cannot be scraped — here's why.
TikTok fires a CAPTCHA challenge the instant any automated browser visits their shop. There is no reliable workaround. Any bot claiming to scrape TikTok Shop is either broken or lying.

What we use instead: Shopee Flash Sale — it scrapes real discounted products directly from Shopee's flash sale API. These are often better-converting than TikTok Shop products anyway because buyers already trust Shopee.
1
Download & run install.bat
One click — installs everything automatically
Required · ~3 min ▾

Your Fiverr delivery includes a ZIP file. Inside it you'll find install.bat — double-clicking it handles all setup automatically.

Steps
  • 1Download the ZIP from your Fiverr order delivery
  • 2Right-click the ZIP → Extract All → choose a location like C:\ProPHBot\
  • 3Open the extracted folder → double-click install.bat
  • 4A terminal window opens and installs everything. Wait for it to say "Setup complete!"
  • 5Press any key to close it
What install.bat does
install.bat output
[OK] Python 3.12.2 found
[OK] pip updated
[2/4] Installing bot packages...
[OK] All packages installed
[3/4] Installing Chromium browser... (~150MB)
[OK] Chromium installed
[4/4] All imports verified
Setup complete! You can now open ProPHBot.exe
⚠️ install.bat requires Python on your PC. If you don't have it yet, download it free at python.org/downloads — tick "Add Python to PATH" during install, then run install.bat again.
  • "Python is not recognized" — install Python from python.org, tick "Add to PATH", then re-run install.bat.
  • Windows blocked the file — right-click install.bat → Properties → tick "Unblock" → OK, then run again.
  • Chromium download is slow — it's 150MB, give it 5–10 minutes on a slow connection.
  • Access denied — right-click install.bat → "Run as administrator".

Next: Export your session cookies
4
Export session cookies
Shopee, Lazada, and Zalora — one by one
Required ▾

The bot logs in as you by using your browser cookies. We export them with a free Chrome extension called Cookie-Editor. This is safe — cookies only work from your IP address.

Install Cookie-Editor (one time)
  • 1In Chrome, go to Cookie-Editor by cgagnier on the Chrome Web Store
  • 2Click Add to Chrome → Add extension
  • 3Pin it to your toolbar for easy access (click the puzzle piece icon in Chrome → pin Cookie-Editor)
Export Shopee cookies
  • 1Open shopee.ph in Chrome and make sure you're logged in
  • 2Click the Cookie-Editor icon in your toolbar
  • 3Click Export at the bottom → choose Export as JSON
  • 4Copy the JSON. Open your bot folder → sessions/ folder → create a file named shopee_session.json → paste the JSON in
Repeat for Lazada and Zalora

Do the same steps for lazada.com.ph → save as lazada_session.json

And for zalora.com.ph → save as zalora_session.json (create a free Zalora account if you don't have one)

⚠️ Cookies expire after a few weeks. If the bot stops scraping a platform, just re-export and overwrite the file. Takes 2 minutes.
Next: Get your Threads API tokens
5
Get Threads API tokens
One token per account — done once via Meta developer tools
Required ▾

The bot posts to Threads using the official API. You need an access token for each of your 5 Threads accounts. This sounds complicated but takes about 10 minutes total.

Create a Meta App (one time)
  • 1Go to developers.facebook.com/apps and log in
  • 2Click Create App → select Other → Business
  • 3Name it anything (e.g. "MyBot"). Fill in your email. Click Create.
  • 4In the app dashboard → Use Cases → find "Access the Threads API" → click it → add threads_basic and threads_content_publish
Add each Threads account as a tester
  • 1In your app: App Roles → Roles → Add Testers
  • 2Add the Instagram usernames for all 5 accounts
  • 3Each account needs to accept the invite: Instagram app → Settings → Security → Tester Invites → Accept
Generate a token for each account
  • 1Go to developers.facebook.com/tools/explorer
  • 2Switch the API base URL to graph.threads.net
  • 3Select your app → click Generate Threads Access Token → log in as account1
  • 4Copy the token. Paste into config.json under publisher.threads_api.accounts[0].access_token
  • 5Repeat in an incognito window for each remaining account
Exchange tokens for 60-day tokens (important!)

The tokens from Graph API Explorer expire in 1 hour. Run this command to convert them to 60-day tokens:

Terminal
$python refresh_tokens.py --exchange
# It will ask for your App ID and App Secret
# Find them at: developers.facebook.com → Your App → App Settings → Basic
[account1] @yourhandle
✅ Long-lived token (60 days)

Configure settings in the GUI

2 min ▾

Open the GUI dashboard first:

Terminal
$ProPHBot.exe (already open)
✅ NutterButters — ProPHBot GUI opens
In the GUI — click ⚙️ Settings in the sidebar
  • 1Open the Settings tab from the left sidebar
  • 2Affiliate IDs — paste your Shopee ID and/or Lazada ID (apply at affiliate.shopee.ph if you don't have one yet)
  • 3Involve Asia — if approved, toggle it on and paste your API key. Leave it off for now if not.
  • 4Telegram — paste your bot token and channel ID if you have a Telegram channel

✅ The GUI Settings tab writes directly to config.json for you. You never need to open a text editor to configure the bot.
💡 Want to check your accounts are set up correctly? Click 📱 Accounts in the sidebar — it shows the status of each account's API token and session file with green/red indicators.
Last step: Run your first test
7
Run your first test from the GUI
Dry run first — no terminal commands needed
Final step ▾

If the dashboard isn't open yet, double-click ProPHBot.exe in your ProPHBot folder.

Step 1 — Click 🧪 Dry Run on the Dashboard

The Dashboard tab has two run buttons at the top right. Click 🧪 Dry Run first — this scrapes products and shows exactly what the bot would post, without actually posting anything.

👁️ The GUI automatically switches to the 📋 Live Log tab so you can watch the bot work in real time — green lines = success, red lines = something needs fixing.

Cycle done — 5 posted (dry run), 0 failed
Step 2 — If it looks good, click ▶ Run Now

Go back to 📊 Dashboard and click ▶ Run Now. This posts to all 5 accounts for real. Watch the Live Log for confirmation.

Step 3 — Turn on the scheduler

Once everything works, click the ⏰ Schedule: OFF button on the Dashboard — it turns orange and becomes Schedule: ON. The bot now runs every 12 hours automatically while the GUI window is open.

⚠️ The scheduler requires the GUI window to stay open. If you close it, scheduling stops. For 24/7 running without leaving the GUI open, you can still use the terminal: Task Scheduler (search Windows for "Task Scheduler" to set it up)
Monitoring — check the 📊 Dashboard stats

The Dashboard shows posts today, products found, active accounts, and cycles run — all updating in real time as the bot runs.

🎉 You're all set! The bot is running and posting trending PH products every 12 hours. Apply for Shopee/Lazada affiliate programs and add your IDs in the GUI Settings tab to start earning commission.
  • EXE won't open — run install.bat again, then try ProPHBot.exe.
  • 0 products scraped — session cookies expired. Go to 📱 Accounts tab — any red indicators? Re-export from Cookie-Editor and replace files in sessions/.
